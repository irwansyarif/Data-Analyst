# Data Dictionary

This document describes the fields used in the Spotify User Demographic Analysis dashboard.

| Field | Description |
|---|---|
| Gender | User gender category |
| Country | Country associated with the user |
| Age | User age |
| Date | Date associated with the record |
| Device | Device used to access Spotify |
| Subscription Type | User subscription category |
| Listening Time | Listening duration metric |
| Skip Rate | Skip behavior metric |
| Offline Listening | Offline listening information |
| Weekly Ad Listening | Weekly ad listening metric |

**Note:** Field definitions should be updated according to the original dataset schema. The exact meaning and unit of each metric depend on the source data.
