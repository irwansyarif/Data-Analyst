# Metric Definitions

This document describes the metrics displayed in the Spotify User Demographic Analysis dashboard.

## Listening Time

Represents the listening time metric displayed in the dashboard.

The unit and aggregation method should be specified according to the original dataset.

## Average Skip Rate

Represents the average skip rate calculated from the available skip-related data.

The exact calculation depends on the source dataset and the definition of the skip rate field.

## Offline Listeners

Represents the number of records or users associated with offline listening.

The aggregation method should be verified against the dataset.

## Weekly Ad Listening

Represents the weekly ad listening metric displayed in the dashboard.

The unit and calculation method should be documented based on the source data.

## User Count

Represents the number of user records included in the analysis.

The counting method should be specified, such as record count or distinct user count, depending on the dataset structure.
